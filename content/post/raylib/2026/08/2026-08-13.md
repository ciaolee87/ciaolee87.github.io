# 시작하기전에
- VCS 는 기본적으로 git을 사용한다.
- 다양한 에셋파일들은 git-lfs 를 사용하여 관리한다.

### 01. 프로젝트 생성하기
1. 깃에 레포지토리를 생선한다.
2. .gitignore 파일 생성
    ~~~gitignore
    # tool
    .idea
    .fleet
    .obsidian
    .vscode
    .vs
    
    # mac
    DS_Store
    .DS_Store
    ~~~
3. git-lfs로 바이너리 파일 등록하기
    - 소스코드가 아닌 바이너리 파일들은 항상 추가하도록 한다.
    - root에 .gitattributes 파일 생성된다.
    ~~~bash
    git lfs track "*.png"
    ~~~


### 02. CMakeLists.txt 작성하기
1. root 폴더에 CMakeLists.txt 파일 생성
    ~~~cmake
    cmake_minimum_required(VERSION 3.14)
    project(first_time_raylib C CXX)
    
    set(CMAKE_CXX_STANDARD 17)
    set(CMAKE_CXX_STANDARD_REQUIRED ON)
    
    include(FetchContent)
    
    FetchContent_Declare(
        raylib
        GIT_REPOSITORY https://github.com/raysan5/raylib.git
        GIT_TAG        6.0 # github 에서 태크 확인하여 입력하기
    )
    
    FetchContent_Declare(
        raylib_cpp
        GIT_REPOSITORY https://github.com/RobLoach/raylib-cpp.git
        GIT_TAG        v6.0.3 # github 에서 태크 확인하여 입력하기
    )
    
    set(BUILD_EXAMPLES OFF CACHE BOOL "" FORCE)
    FetchContent_MakeAvailable(raylib raylib_cpp)
    
    add_executable(helloWorld src/main.cpp)
    target_link_libraries(helloWorld PRIVATE raylib raylib_cpp)
    ~~~
2. 트러블슈팅
   - 불러오는 모듈이름 스네이크 케이스로하기 (케밥케이스로 할때 안되었음)
   - Clion 에서 Tools > CMake > Clean build ... 실행하면 헤더 불러오기 실패 에러 수정가능
   - Makefile 로 실행시 Unix 시스템으로 빌드했다고 안됨 => Clion 의 빌드시스템으로 빌드하기


### 03. hello world 추가하기
1. root/src/main.cpp 작성하기
    ~~~cpp
    #include "raylib-cpp.hpp" // raylib-cpp 헤더 불러오기
    
    int main() {
    // C++ 객체지향 스타일 사용 가능 (자동 메모리 해제)
    raylib::Window window(800, 450, "raylib-cpp Example");
    
        SetTargetFPS(60);
    
        while (!raylib::Window::ShouldClose()) {
            BeginDrawing();
            window.ClearBackground(RAYWHITE);
    
            DrawText("Hello raylib-cpp!", 190, 200, 20, LIGHTGRAY);
    
            EndDrawing();
        }
    
        return 0;
    } 
    ~~~
