#toolchain  #cpp  #cmake  #vcpkg 

C++ 사용을 위한 기본 관리 도구#

  • 기본적으로 모든 작업은 MacOS 기준으로 작성했다.
  • 추후 필요하다면 Windows 환경에서도 사용할수 있도록 내용을 추가할 예정

대표적인 관리도구#

  1. CMake 빌드 및 설정
    • CMake 홈페이지
  2. vcpkg 패키지 관리
    • microsoft 에서 관리하는 c++ 패키지 매니저
    • vcpkg 홈페이지
    • vcpkg 레포지토리

cmake 설치하기#

  • MacOS 기준 Brew로 설치하는 것이 제일 관리하기 편하다. 
    # brew 최신버전으로 업데이트
brew update
# cmake 실행
brew install cmake
  • 버전을 꼭 알아두는 것이 좋다.
    • CMakeLists.txt (설정파일)에서 최소 CMake 버전을 꼭 입력해야 한다.
    cmake --version
# cmake version 3.31.4

vcpkg 설치하기#

  1. 레포지토리에서 직접 다운로드 받아 빌드한다.
  • 바이너리를 다운받아도 되고 레포지토리를 다운받아서 직접 빌드하해도 된다.
  • 레포지토리를 클론하고 bootstrap-vcpkg.sh 을 실행한다.
  • vcpkg 프로그램이 레포지토리 root에 자동으로 빌드되어 생성된다. 
      sh bootstrap-vcpkg.sh

  1. .zshrc 등에 /bin/ 폴더 추가하여 프로그램을 바로 실행할수 있도록 준비한다.

    # zsh 사용자의 경우 .zshrc 에 다음을 추가한다.
# bash 사용자의 경우 .bashr
# 필자는 계정루트에 /sdk/cpp/vcpkg 에 레포지토리를 clone 하고 vcpkg 파일을 빌드하여 위치시켰다.
path=$path:$HOME/sdk/cpp/vcpkg

  2. 또는 brew 에서 다운로드받아 설치한다

    brew install vcpkg
